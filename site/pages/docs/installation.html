Installation

Content Helper ist eine Windows-App für Windows 10 und 11. Es gibt kein Konto und keinen Server – alles läuft auf deinem PC.

Herunterladen

FassungFür wen
Installer Content-Helper-Setup-{{version}}.exeDer Normalfall: Startmenü-Eintrag, Aktualisierung von selbst.
Portable Fassung Content-Helper-{{version}}.exeOhne Installation, etwa vom USB-Stick.

Ältere Versionen und die Änderungen je Version stehen unter Releases auf GitHub.

Erster Start

Windows SmartScreen meldet sich, weil die Datei nicht signiert ist. Klicke auf Weitere Informationen und dann Trotzdem ausführen. Das passiert nur beim ersten Mal.

Danach lohnt sich als Erstes: unter Verbindungen deinen YouTube-Kanal eintragen und dich bei Twitch anmelden – die App holt dann deine bisherigen Videos und Streams und der Assistent hat etwas zum Auswerten.

Updates

Beim Start schaut die App nach einer neuen Version, lädt sie im Hintergrund und spielt sie beim nächsten Neustart ein. Wer nicht warten will, klickt in der Seitenleiste auf Neu starten und einspielen. Von Hand prüfen geht über Update prüfen unten in der Seitenleiste.

Im Hintergrund weiterlaufen

Beim Schließen des Fensters bleibt Content Helper im Infobereich neben der Uhr aktiv – sonst könnten Termine nicht rausgehen. Unter Veröffentlichen lässt sich außerdem Mit Windows starten einschalten. Ganz beenden geht über das Symbol im Infobereich → Beenden.

Deine Daten

Alles liegt als lesbares JSON unter %APPDATA%\Content Helper\data. Jeden Tag entsteht automatisch ein Schnappschuss, und unter Einstellungen → Daten kannst du jederzeit eine vollständige Sicherung exportieren und wieder einlesen.

Deinstallieren

Über Windows-Einstellungen → Apps. Deine Daten bleiben dabei unter %APPDATA%\Content Helper liegen – wer sie auch loswerden will, löscht diesen Ordner.

Probleme? Issue auf GitHub öffnen.
