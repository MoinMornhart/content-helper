Several PCs

Streaming PC at home, laptop on the road – both see the same posts, ideas and numbers, even in different places. There is no account and no server for this: the transport is a folder you already sync with OneDrive, Dropbox, Google Drive or iCloud.

Setting it up

  1. First PC: Setup → Link PCs, choose the cloud folder and click Create sync space. You get a code like CH-XXXXX-XXXXX-XXXXX-XXXXX.
  2. Another PC: choose the same cloud folder – it may have a different name or location there – enter the code, Join.

Changes usually arrive within seconds, sometimes after a minute – depending on how fast the cloud client is.

What syncs

SyncedStays per PC
Posts, ideas, scripts, numbers, channels, time slots, weekly goalsLook, language, sign-ins, video and image files

How it's protected

  • Encrypted: the code is also the key (AES-256). The cloud folder only contains unreadable files – your provider sees nothing. Treat the code like a password.
  • No conflict copies: each PC only writes its own files.
  • The newer change wins, per entry. Deleted items stay deleted.
  • Nothing twice: only one PC fetches YouTube and Twitch, and only that PC publishes. You can change which one.

You can unlink a PC at any time under Link PCs → Unlink this PC. Its data stays, and the other PCs are not affected.
