Installation

Content Helper is a Windows app for Windows 10 and 11. There is no account and no server – everything runs on your PC.

Download

VersionFor whom
Installer Content-Helper-Setup-{{version}}.exeThe usual choice: Start menu entry, updates itself.
Portable version Content-Helper-{{version}}.exeNo installation, e.g. from a USB stick.

Older versions and the changes in each version are listed under Releases on GitHub.

First start

Windows SmartScreen shows a warning because the file is not signed. Click More info and then Run anyway. This only happens the first time.

A good first step: under Connections, add your YouTube channel and sign in to Twitch – the app then fetches your existing videos and streams, and the Assistant has something to analyze.

Updates

On every start the app checks for a new version, downloads it in the background and installs it on the next restart. If you don't want to wait, click Restart and install in the sidebar. You can check manually with Check for updates at the bottom of the sidebar.

Running in the background

When you close the window, Content Helper keeps running in the system tray next to the clock – otherwise scheduled posts couldn't go out. Under Publish you can also turn on Start with Windows. To quit completely, use the tray icon → Quit.

Your data

Everything is stored as readable JSON under %APPDATA%\Content Helper\data. A snapshot is created automatically every day, and under Settings → Data you can export and re-import a full backup at any time.

Uninstalling

Via Windows Settings → Apps. Your data stays under %APPDATA%\Content Helper – delete that folder if you want it gone too.
